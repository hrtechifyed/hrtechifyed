## 🧠 About Anurag

I am an **HR professional, not a professional coder**.

My core work is in **strategic HR, talent management, succession, leadership development, organizational effectiveness, performance, workforce decisions and employee experience**.

What makes this GitHub profile a little different is that I use modern technology to **turn HR ideas into working experiments and prototypes**.

I start with the people problem first:

```text
Workplace problem
      ↓
HR / organizational logic
      ↓
User experience and decision flow
      ↓
AI-assisted building + automation
      ↓
Working prototype
      ↓
Test, learn, improve
```

I do **not** position myself as a software engineer or claim deep programming-language expertise. I use AI-assisted development, APIs, automation platforms, databases and cloud services as tools to explore how better HR systems can be designed.

My professional experience spans **Siemens, Amazon and Flipkart**, with work across talent strategy, HR business partnering, organization design, performance, rewards, leadership pipelines, change and HR technology experimentation.
